# desk-organizer
A deks organizer with flower shaped pencil holder and a drawer with flower knob
# Directions
put the drawer container with the pen holder print and glue them together the drawer is supossed to slide in the container so just put it in the container. Try to glue the knob exactly in the middle of the drawer before putting it in. The final look should look like this:

# How?
Used fusion and made the parts each on a different file. SKetched and exruded them. For the drawers the perimeter was a bit smaller for high precison and easy fitting
